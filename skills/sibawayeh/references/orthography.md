# Orthography, punctuation and digits

Read this when you are unsure of a hamza seat, ة/ه، ى/ي, a joined or split word, tanween, Arabic punctuation, digits, or how to lay out mixed Arabic and English in Markdown.

Markers: ✗ wrong, ✓ correct. [VARIES] = regional variation; both forms are correct, pick the default and stay consistent.

## House conventions (pick once, never mix in one text)

| Topic | Default | Avoid |
|---|---|---|
| Tanween fath | ✓ كتابًا (mark on the letter before the alif) | ✗ كتاباً mixed with كتابًا in one text |
| Damma hamza after sukun or long vowel | ✓ مسؤول، شؤون، يقرؤون | ✗ مسئول، شئون، يقرءون (Egyptian print [VARIES]; never mix) |
| 100 | ✓ مئة، ثلاثمئة | ✗ مائة، ثلاثمائة (traditional [VARIES]; never mix) |
| Final ي | ✓ في، الذي (always dotted) | ✗ فى، الذى (Egyptian print) |
| Punctuation | ✓ ، ؛ ؟ « » | ✗ , ; ? between Arabic words |
| Digits | ✓ Western 0–9 | ✗ Persian ۰–۹; ✗ mixing 3 and ٣ |
| Tatweel and italics | ✓ none in running text | ✗ مـحـمـد، ✗ *italic Arabic* (use **bold** or «») |
| هيئة | ✓ هيئة (near-universal) | — (هيأة is the strict-rule form [VARIES]) |
| موسيقى | ✓ موسيقى | — (موسيقا allowed by academies) |

## 1. Hamza

### 1.1 Wasl (bare ا) vs qat' (أ/إ) at the start of a word

Test: put و before the word. If the hamza is still heard (وأكل، وإنّ) it is qat': write أ/إ. If it disappears (واكتب، واسمه) it is wasl: write ا.

| Bare ا (wasl) only in | ✓ correct | ✗ wrong |
|---|---|---|
| The ten nouns, singular and dual: ابن، ابنة، اسم، اثنان، اثنتان، امرؤ، امرأة | ✓ ابن، اسم، اثنان، اثنتين، امرأة | ✗ إبن، إسم، إثنان، إثنين، إمرأة |
| The article ال | ✓ الكتاب | ✗ ألكتاب |
| Form I imperative | ✓ اكتب، اذهب، اجلس | ✗ إكتب، أذهب (as an imperative) |
| Past, imperative, masdar of forms VII, VIII, IX | ✓ انطلاق، انتظار، اجتماع، اقتصاد، انتخابات، اختيار، اتصال، احترام، اهتمام، الاطّلاع | ✗ إنتظار، إجتماع، إقتصاد، إنتخابات، إختيار، إتصال، إحترام، إهتمام، الإطلاع |
| Past, imperative, masdar of form X | ✓ استخدام، استخدم، استثمار، استثناء، استقلال، استعمال، استيراد | ✗ إستخدام، إستثناء، إستقلال، إستعمال، إستيراد |

Everything else takes a written hamza:

| Category | ✓ correct | ✗ wrong |
|---|---|---|
| Particles | ✓ إنّ، أنّ، إن، أن، أو، إلى، إلا، إذا، إذ، إذن، أي، أمّا، إمّا | ✗ ان، الى، الا، اذا، او، اي، اما |
| Pronouns | ✓ أنا، أنت، أنتم، إيّاك | ✗ انا، انت، انتم |
| Form IV past and masdar | ✓ أعلن/إعلان، أنشأ/إنشاء، أبدع/إبداع، أصدر/إصدار، أضاف/إضافة، إرسال، إجراء | ✗ اعلان، انشاء، ابداع، اصدار، اضافة، ارسال، اجراء |
| Hamzated roots | ✓ أخذ، أكل، أمر، أمل | ✗ اخذ، اكل |
| First-person present | ✓ أكتب، أستخدم، أنتظر | ✗ استخدم (meaning "I use") |
| Elatives | ✓ أكبر، أفضل، أكثر، أول | ✗ اكبر، افضل، اكثر، اول |
| Plurals أفعال/أفعلة | ✓ أبناء، أسماء، أعمال، أسئلة | ✗ ابناء، اسماء، اعمال، اسئلة |
| Other nouns | ✓ أب، أم، أخ، أرض، إنسان، أمس، أهل، أستاذ | ✗ ارض، انسان، امس، اهل |
| Loanwords | ✓ إنترنت، إلكتروني، أكاديمية، أوروبا، إيطاليا | — (إستراتيجية/استراتيجية [VARIES]) |

- Egyptian web text often drops أ/إ entirely (✗ الى، ان، اذا). Formal MSA requires the hamza: always write it.
- A prefix keeps the hamza seat: ✓ بأن، لأن، فإن، كأن، سأذهب، بإمكان، لإنجاز. ✗ لان، بان (for بأن). Fixed exceptions: لئلا، لئن، هؤلاء، يومئذ، حينئذ.
- إنّ vs أنّ is grammar: see grammar.md §5. ✗ قال أنّه → ✓ قال إنّه.

### 1.2 Wasl alif dropped, madda

| Rule | ✓ correct | ✗ wrong |
|---|---|---|
| لـ + ال → لل | ✓ للطالب، لله | ✗ لالطالب |
| اسم loses its alif only in the full basmala | ✓ بسم الله الرحمن الرحيم / ✓ باسم الشعب | ✗ بسم الشعب |
| ابن between two names (son of father) loses its alif | ✓ محمد بن عبد الله، عمر بن الخطاب | ✗ محمد ابن عبد الله (in a name chain) |
| ابن keeps its alif at line start or as a predicate | ✓ ابن خلدون / ✓ هذا ابن خالد | ✗ قال إبن خلدون |
| أ + ا or أ + أ → آ | ✓ آمن، آخر، القرآن، مرآة، آلة، الآن | ✗ أامن، قرأن، ألآن، الان |

### 1.3 Middle hamza

Compare the hamza's vowel with the vowel before it; the stronger wins: kasra (ئ) > damma (ؤ) > fatha (أ) > sukun.

| Seat | ✓ correct | ✗ wrong |
|---|---|---|
| ئ | ✓ سُئل، رئيس، بئر، فئة، مسائل، أسئلة، مئات، يئس | ✗ سؤل، رأيس، أسألة |
| ؤ | ✓ سؤال، مؤمن، رؤوس، تفاؤل، تشاؤم، تساؤل، يؤدي، مؤسسة | ✗ سئال، تفائل، تشائم، تسائل (noun) |
| أ | ✓ سأل، رأس، يأس، مسألة، جرأة، نشأة، يتأخر، مأساة | ✗ مسئلة، جرئة، نشئة |
| ء after long ā (fatha hamza) | ✓ تساءل، يتساءل، قراءة، براءة، إجراءات | ✗ تسائل (verb)، يتسائل، قرائة، برائة، اجرائات |
| ئ after ي with sukun | ✓ هيئة، بيئة، شيئان، خطيئة، بريئة | — |

### 1.4 Final hamza

Only the letter before it decides.

| Before the hamza | Seat | ✓ correct | ✗ wrong |
|---|---|---|---|
| fatha | أ | ✓ بدأ، قرأ، مبدأ، يقرأ، خطأ، نبأ، منشأ | ✗ خطئ (noun)، يقرء |
| damma | ؤ | ✓ تباطؤ، تكافؤ، تواطؤ، يجرؤ | ✗ تباطئ، تكافئ (noun) |
| kasra | ئ | ✓ شاطئ، قارئ، مبادئ، ناشئ، طوارئ، لاجئ | ✗ شاطيء، قاريء، مباديء، شاطىء |
| sukun or long vowel | ء | ✓ سماء، شيء، جزء، ضوء، بطء، مجيء، بريء، بطيء، هدوء | ✗ شئ، شيئ، بريئ، البرئ، بطيئ، جزئ |

With a suffix the hamza becomes middle (جزؤه/جزأه/جزئه); most writers keep one form. Low priority.

## 2. Final letters

### 2.1 ة vs ه

ة is the feminine ending (pronounced t when a suffix is added: مدرسة → مدرستي). ه is a root letter or the pronoun "his".

| ✓ correct | ✗ wrong |
|---|---|
| ✓ مدرسة، حياة، صلاة، فتاة، قضاة، الجامعة، الحكومة، الشبكة، اللغة | ✗ مدرسه، حياه، الجامعه، الحكومه، الشبكه، اللغه، قضاه |
| ✓ مياه، اتجاه، انتباه، شفاه، وجه، الله | ✗ مياة، اتجاة، انتباة، وجة |
| ✓ رسالته (ة → ت before a suffix) | ✗ رسالةه |
| ✓ عادةً، خاصةً، مرةً، نتيجةً، فجأةً (no alif after ة) | ✗ عادتاً، خاصتاً، مرتاً، نتيجتاً |

Real pairs, decide by meaning: كتابة (writing) / كتابه (his book).

### 2.2 ى vs ي, and final ا

| Rule | ✓ correct | ✗ wrong |
|---|---|---|
| ى = final alif sound, no dots | ✓ على، إلى، حتى، متى، لدى، مستشفى، مستوى، معنى، أخرى، كبرى، ذكرى، فوضى | ✗ الي المستشفي، حتي، متي، علي البيت |
| ي = ya sound, always dotted | ✓ في، الذي، التي، القاضي، يمشي، كرسي | ✗ فى، الذى، التى |
| 3-letter words from و → ا | ✓ دعا، نجا، شكا، عفا، بدا، علا | ✗ دعى، نجى، شكى |
| 3-letter words from ي → ى | ✓ رمى، سعى، قضى، مشى، بنى، جرى | ✗ رما، سعا، قضا، مشا |
| 4+ letters → ى | ✓ أعطى، استدعى، انتهى، اشترى، تلقى، منتدى | ✗ أعطا، استدعا، انتها، اشترا |
| …but ا after ي | ✓ أحيا، دنيا، عليا، قضايا، زوايا، هدايا (name يحيى is fixed) | — |
| Foreign words → ا | ✓ أمريكا، فرنسا، أوروبا، سينما (fixed: موسى، عيسى) | — |
| Particles are fixed | ✓ إذا، لولا، مهما، هذا / ✓ إلى، على، حتى، متى، لدى | — |
| ى → ا before a suffix | ✓ عليه، إليه، لديك، مستشفاه | ✗ علىه، مستشفىه |

Real pairs, decide by meaning: على/عليّ، إلى/إليّ، لدى/لديّ، مبنى/مبني، معنى/معني، مستوى/مستوي.

## 4. Joined and split words

| Rule | ✓ correct | ✗ wrong |
|---|---|---|
| من/عن + ما/من join with shadda | ✓ ممّا، ممّن، عمّا، عمّن | ✗ من ما، عن ما، من من |
| ما-compounds join | ✓ ربما، إنما، عندما، حينما، مثلما، كيفما، مهما، أينما، حيثما، طالما، بينما | ✗ رب ما، إن ما، مه ما |
| لا سيّما is two words | ✓ لا سيّما، ولا سيّما | ✗ لاسيما |
| إن شاء الله is three words | ✓ إن شاء الله | ✗ إنشاء الله |
| أن + لا → ألّا | ✓ يجب ألّا تتأخر | — (أن لا is widely accepted [VARIES]) |
| لئلا، لكيلا | ✓ لئلا، لكيلا، لكي لا | ✗ لأن لا (for لئلا) |
| إذ joins time nouns | ✓ يومئذ، حينئذ، وقتئذ | ✗ يوم إذ، حين إذ |
| Hundreds join; 11–19 split | ✓ ثلاثمئة، خمسمئة / ✓ خمسة عشر | ✗ خمسةعشر |
| يا stands alone | ✓ يا محمد | ✗ يامحمد |
| حِدَة | ✓ على حِدَة | ✗ على حدى، على حدا |

- كلّما (whenever) vs كلّ ما (everything that): ✓ كلّما زرته أكرمني / ✓ كلّ ما قاله صحيح.
- عبد الله is split in formal MSA; عبدالله is common in the Gulf [VARIES]. Never "fix" a person's own name.

## 5. Tanween fath

Indefinite accusative = ـًا, except after ة، ى، and after ء that follows ا.

| Ending | ✓ correct | ✗ wrong |
|---|---|---|
| ordinary | ✓ كتابًا، شكرًا، أيضًا، جدًّا، دائمًا | ✗ كتابً، شكرً |
| ة | ✓ مدرسةً، عادةً، فجأةً | ✗ عادتاً، مدرسةًا |
| ى | ✓ هدًى، مستشفًى، معنًى | ✗ فتىا |
| اء | ✓ سماءً، بناءً، إجراءً، مساءً | ✗ سماءًا، بناءاً |
| ء after a non-joining letter or و | ✓ جزءًا، ضوءًا، بدءًا، هدوءًا | ✗ جزئاً، ضوئاً |
| ء after a joining letter (hamza moves to ئ) | ✓ شيئًا، عبئًا، بطئًا، دفئًا | ✗ شيءًا، شيأً |
| final أ | ✓ خطأً، مبدأً، ملجأً | ✗ خطأًا، خطئاً |

Placement: ✓ ـًا (default). ✗ mixing ـًا with ـاً in one text. In unvocalized text, tanween is normally written only on frequent adverbs (أيضًا، جدًا، شكرًا): that is fine.

## 6. Punctuation

| Mark | Use | ✓ correct | ✗ wrong |
|---|---|---|---|
| ، U+060C | between linked clauses, list items, after a vocative, after نعم/لا | ✓ جاء الصيف، واشتد الحر. | ✗ جاء الصيف, واشتد الحر |
| ؛ U+061B | before a cause or result clause | ✓ لم يحضر؛ لأنه كان مريضًا. / ✓ اجتهد؛ فنجح. | ✗ لم يحضر; لأنه |
| ؟ U+061F | after a direct question only | ✓ هل حضرت؟ / ✓ سألته هل حضر. | ✗ هل حضرت? / ✗ سألته هل حضر؟ |
| . | end of sentence, abbreviations (د. محمد) | ✓ . | ✗ ۔ (Urdu) |
| : | before speech, lists, definitions, examples | ✓ قال: «سأحضر» | — |
| « » | quotations, titles, a word cited as a word | ✓ «النص» | ✗ mixing «» with “…” in one text |
| ( ) | glosses, English equivalents, dates | ✓ (API) | — |
| ﴿ ﴾ | Qur'anic text only | ✓ ﴿…﴾ | — |

Spacing: no space before ، ؛ ؟ ! . : or a closing bracket/quote; one space after; no space just inside brackets or quotes.

- ✓ `قال: «سأحضر غدًا»، ثم غادر (مسرعًا).`
- ✗ `قال :« سأحضر غدًا » ، ثم غادر ( مسرعًا ) .`

- Never put a comma between a verb and its subject, a subject and its predicate, or the two terms of an idafa.
- Don't comma-splice every clause English-style: Arabic links clauses with و، فـ، ثم, or ends the sentence. Don't end every list item with a period.
- ؛ before لأنّ is the textbook rule; a ، there is common [VARIES].
- `؟!` and `!!` are informal: avoid them in formal writing.
- Latin punctuation inside English segments stays Latin: ✓ (Python, Java).

## 7. Digits

| Rule | ✓ correct | ✗ wrong |
|---|---|---|
| One system per text; default Western | ✓ 3 ملفات و25 سطرًا | ✗ 3 ملفات و٢٥ سطرًا |
| Arabic-Indic only when the user writes with them | ✓ ٣ ملفات و٢٥ سطرًا | — |
| Never Persian digits | ✓ 4، 5، 6 | ✗ ۴، ۵، ۶ |
| Always Western in code, versions, URLs, paths, commands, units with Latin symbols | ✓ Python 3.12، 5 GB | ✗ `٣٫١٢` in code |
| Separators match the system | ✓ 3.14، 1,000، 25% / ✓ ٣٫١٤، ١٬٠٠٠، ٢٥٪ | ✗ 1،000 (Arabic comma inside a number) |
| Order: most significant digit first | ✓ 2026 | ✗ 6202 (never reverse digits) |
| Ordinals in prose as words | ✓ الفصل الثالث | — |

Eras: هـ for Hijri, م for Gregorian (✓ 1448هـ / 2026م).

## 8. Mixed Arabic and English (RTL safety)

| Rule | ✓ correct | ✗ wrong |
|---|---|---|
| Start every line, heading and bullet with an Arabic word | ✓ `- مكتبة React تسهّل…` | ✗ `- React مكتبة تسهّل…` / ✗ `- 3 خطوات` |
| Keep English inside parentheses or backticks mid-sentence | ✓ نستخدم `git status` للتحقق | — |
| Arabic punctuation outside code spans | ✓ شغّل `npm test`، ثم… | ✗ شغّل `npm test،` ثم… |
| Don't end a line with an English word or code if avoidable | ✓ شغّل الأمر `make` أولًا. | — |
| No Arabic prefix glued to a Latin word | ✓ باستخدام Git | ✗ بـGit ([VARIES]: بـ Git with a space is a common tech convention) |
| No Arabic morphology on English words | ✓ الإيداعات (commits) / ✓ عمليات commit | ✗ الـ commits، ✗ deployات |
| Type brackets in logical order; never type `)` first to make it look right | ✓ (مثال) | — |
| Code, identifiers, file names stay Latin in backticks | ✓ `config.yaml` | ✗ transliterating identifiers |

## 9. Tatweel, Unicode, diacritics

- Tatweel ـ (U+0640): never in running text. Allowed only in هـ after a year, a prefix before Latin (بـ Git), and when citing a letter or affix (الـ، ـة).
- Persian/Urdu look-alikes are always wrong in Arabic: ✗ ی ک ہ ە ۃ → ✓ ي ك ه ة. The checker fixes ک → ك, ہ → ه and ی → ي inside a word. A word-final ی can stand for ي or ى (✗ علی → ✓ على, ✗ کرسی → ✓ كرسي), so the checker only warns there and you choose. It skips words that contain پ چ ژ گ (quoted Persian) and does not catch ە or ۃ: replace those yourself.
- Presentation forms (ﻛﺘﺎﺏ) → base letters. Word ligatures and signs (ﷲ ﷺ ﷼) are left as written. No ZWNJ/ZWJ inside Arabic words.
- Diacritics: prose is unvocalized. Add a mark only to remove real ambiguity (✓ علّم/علم، يُعتبر، عِلم/عَلَم). A wrong mark is worse than none. ✗ random partial vocalization like كتبَ الطالبِ.
