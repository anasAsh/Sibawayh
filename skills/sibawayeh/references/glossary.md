# Tech glossary (English → Arabic)

Read this when writing about software, the web, AI or data and you need the standard Arabic term.

How to use it (see style.md §6):

- Use the Arabic term. On first mention add the English in parentheses: «واجهة برمجة التطبيقات (API)». After that use one form consistently.
- Notes lists accepted alternatives; pick one per text and keep it.
- "Transliteration" marks terms whose Arabised form is the established one.
- Identifiers, commands, file names, flags and brand names stay in Latin script, in backticks.
- If a term isn't here and you're unsure, don't coin one: write the English in parentheses.
