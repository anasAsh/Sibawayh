# Grammar reference

Read this before writing numbers with counted nouns, plurals of things, sound plurals or duals, إنّ/أنّ, conditionals or relative clauses, and when reviewing any of them.

Markers: ✗ wrong, ✓ correct, → fix. "Contested" = authorities disagree; both forms are acceptable, never flag the common one.

## 1. Agreement

### 1.1 Non-human plurals (the error LLMs make most)

A plural of a **thing** (files, tools, countries, companies, models, options) takes **feminine singular** agreement: verb with ت, adjective with ة, pronoun ـها, demonstrative هذه/تلك, relative التي.

| ✗ wrong | ✓ correct |
|---|---|
| ✗ الكتب مفيدون | ✓ الكتب مفيدة |
| ✗ الملفات موجودون | ✓ الملفات موجودة |
| ✗ الخيارات المتاحون | ✓ الخيارات المتاحة |
| ✗ المشاريع وتمويلهم | ✓ المشاريع وتمويلها |
| ✗ هؤلاء الدول | ✓ هذه الدول |
| ✗ الدول الذين / الأدوات الذين | ✓ الدول التي / الأدوات التي |
| ✗ الشركات أعلنوا | ✓ الشركات أعلنت |
| ✗ الخطط التي وضعناهم | ✓ الخطط التي وضعناها |
| ✗ الدول كلهم | ✓ الدول كلها |

- People stay human plural: المستخدمون/المطورون → هم، الذين، ـوا.
- Collectives (الحكومة، الشركة، الفريق، الناس): singular by form is safest; plural by meaning is attested (الناس يقولون / الناس تقول, both fine).
- Human feminine plural: prefer اللاتي/اللواتي and ـن verbs (الطالبات اللاتي نجحن). Using التي and feminine singular is tolerated (contested).

### 1.2 Verb and subject

| Rule | ✗ wrong | ✓ correct |
|---|---|---|
| Verb **before** an overt plural/dual subject stays singular (gender still agrees) | ✗ ذهبوا الطلاب / ✗ نجحا الطالبان | ✓ ذهب الطلاب / ✓ نجح الطالبان / ✓ ذهبت الطالبات |
| Verb **after** its subject agrees fully | ✗ الطلاب ذهب / ✗ الطالبتان نجحت | ✓ الطلاب ذهبوا / ✓ الطالبتان نجحتا |
| Feminine subject → ت on the verb | ✗ قال الوزيرة / ✗ الحكومة أعلن | ✓ قالت الوزيرة / ✓ الحكومة أعلنت |
| Sound masculine plural subject → masculine verb | ✗ حضرت المعلمون | ✓ حضر المعلمون |
| Organizations and most countries are feminine | ✗ أعلن الولايات المتحدة | ✓ أعلنت الولايات المتحدة / ✓ قالت الأمم المتحدة |
| Quantifier subject (عدد من، بعض، معظم): verb before it is masculine singular | ✗ حضروا عدد من الطلاب | ✓ حضر عدد من الطلاب |
| Passive subject follows the same rules | ✗ اعتقلوا المتظاهرون | ✓ اعتُقل المتظاهرون |

- Masculine country names: العراق، الأردن، لبنان، السودان، المغرب، اليمن (✓ أعلن العراق). لبنان/الأردن are sometimes feminine (contested).
- معظم الطلاب حضروا / حضر: both accepted.
- Verb separated from a feminine subject: ت optional, but default to ت (✓ أعلنت أمس الوزارة).

### 1.3 Adjectives, dual, كلا/كلتا

| ✗ wrong | ✓ correct | Note |
|---|---|---|
| ✗ المدينة الكبير | ✓ المدينة الكبيرة | gender |
| ✗ الحرب العالمي / ✗ حرب طاحن | ✓ الحرب العالمية / ✓ حرب طاحنة | feminine without ة: شمس، أرض، حرب، نفس، دار، ريح، بئر، عين، يد، نار |
| ✗ طالبتان متفوقتين (nominative) | ✓ طالبتان متفوقتان | case on duals |
| ✗ في هذان اليومين | ✓ في هذين اليومين | demonstrative in case |
| ✗ كلا الحالتين | ✓ كلتا الحالتين | كلتا with feminine |
| ✗ رأيت كلاهما | ✓ رأيتهما كليهما | كلا/كلتا inflect only with a pronoun suffix |

Both genders: طريق، سوق، سكين، حال، سبيل.

## 2. Numbers and counted nouns

Gender is judged by the **singular** of the counted noun (حمّام → ✓ ثلاثة حمّامات، ساحة → ✓ ثلاث ساحات). For large or technical numbers, prefer digits (✓ 123 ملفًا، 1500 دولار): it sidesteps most errors.

| Number | Number's gender | Counted noun | ✓ correct | ✗ wrong → fix |
|---|---|---|---|---|
| 1, 2 | agrees; comes **after** the noun | — | ✓ كتاب واحد / ✓ مدينة واحدة / ✓ كتابان اثنان | ✗ واحد كتاب → كتاب واحد; ✗ اثنان كتب → كتابان |
| 3–10 | **reverse** (masc. noun → ة) | genitive **plural** | ✓ ثلاثة كتب / ✓ ثلاث سيارات / ✓ خمسة أيام / ✓ سبع سنوات | ✗ ثلاث أيام → ثلاثة; ✗ خمسة سنوات → خمس; ✗ ثلاثة طالب → ثلاثة طلاب |
| 8 | ثمانية (m.); ثماني + fem. noun | genitive plural | ✓ ثمانية أشهر / ✓ ثماني سنوات | ✗ ثمانية سنوات → ثماني (ثمان سنوات is contested) |
| 10 | عشرة (m.) / عشر (f.) | genitive plural | ✓ عشرة أيام / ✓ عشر ساعات | ✗ عشرة ساعات → عشر |
| 11, 12 | **both parts agree** | accusative **singular** | ✓ أحد عشر كوكبًا / ✓ إحدى عشرة دولةً / ✓ اثنا عشر شهرًا (nom.) / ✓ بعد اثني عشر شهرًا | ✗ إحدى عشر دولة → إحدى عشرة; ✗ أحد عشر خطوة → إحدى عشرة خطوةً; ✗ بعد اثنا عشر → اثني عشر |
| 13–19 | first part **reverse**, عشر/عشرة **agrees** (never ة on both) | accusative singular | ✓ ثلاثة عشر طالبًا / ✓ ثلاث عشرة طالبةً / ✓ خمس عشرة دقيقةً | ✗ ثلاثة عشرة طالبًا → ثلاثة عشر; ✗ خمسة عشر دقيقة → خمس عشرة دقيقةً; ✗ خمسة عشر ملفات → ملفًا |
| 20–90 | invariable; ـون nom. / ـين acc.+gen. | accusative singular | ✓ عشرون طالبًا / ✓ في ثلاثين يومًا | ✗ عشرون طلاب → طالبًا; ✗ بعد ثلاثون عامًا → ثلاثين |
| 21–99 | unit by its own rule + و + ten | accusative singular | ✓ واحد وعشرون عامًا / ✓ إحدى وعشرون دولةً / ✓ ثلاث وعشرون سنةً / ✓ خمسة وأربعون يومًا | ✗ ثلاثة وعشرون سنة → ثلاث وعشرون سنةً |
| 100, 1000 | invariable; dual مئتان/ألفان (مئتا/ألفا in idafa) | genitive **singular** | ✓ مئة كتاب / ✓ ألف سيارة / ✓ مئتا موظف | ✗ مئة كتب → مئة كتاب; ✗ ألف دولارًا → ألف دولار |
| 300–900 | مئة stays singular, usually joined | genitive singular | ✓ ثلاثمئة طالب / ✓ خمسمئة | ✗ ثلاث مئات طالب → ثلاثمئة طالب |
| 3000–10000 | ألف is masculine → ة on 3–10; plural آلاف | genitive | ✓ ثلاثة آلاف / ✓ عشرة آلاف دولار | ✗ ثلاث آلاف → ثلاثة آلاف |
| مليون، مليار | masculine; ملايين، مليارات | genitive singular | ✓ ثلاثة ملايين نسمة / ✓ خمسة مليارات دولار | ✗ ثلاث ملايين → ثلاثة ملايين |
| mixed | noun follows the **last** number | — | ✓ ألف ومئة كتاب / ✓ مئة وخمسون طالبًا | ✗ ألف وعشرون كتاب → كتابًا |

### 2.1 Definite numbers, ordinals, number-like words

| Rule | ✓ correct | ✗ wrong |
|---|---|---|
| Definite 3–10: number after the noun as adjective (gender still reversed) is the classical form | ✓ الأيام الثلاثة / ✓ السنوات الخمس | — (ال on the number, as in الخمسة كتب, is Academy-approved: never flag) |
| Ordinals (فاعل) **agree**, no reversal | ✓ الفصل الثالث / ✓ الصفحة الثالثة / ✓ المرة الأولى | ✗ الصفحة الثالث |
| 11th, 21st…: الحادي/الحادية, not الواحد | ✓ الطابق الحادي عشر / ✓ القرن الحادي والعشرون / ✓ في القرن الحادي والعشرين | ✗ القرن الواحد والعشرين / ✗ الواحد عشر |
| Compound ordinals: both parts agree | ✓ الدورة الخامسة عشرة | ✗ الدورة الخامس عشر |
| أحد/إحدى agree with the noun | ✓ إحدى الطالبات / ✓ أحد الطلاب | ✗ أحد الطالبات |
| بضع/بضعة like 3–10 | ✓ بضعة أيام / ✓ بضع سنوات | ✗ بضعة سنوات / ✗ بضع أيام |
| كم (question) + accusative singular | ✓ كم كتابًا قرأت؟ | ✗ كم كتب قرأت؟ |
| عدة: gender does not change | ✓ عدة دول / ✓ دول عدة | — |

## 3. Visible endings

Short case vowels are invisible; these endings are not. Check them every time.

| Position | Sound masc. plural | Dual | ذو |
|---|---|---|---|
| Nominative: subject، مبتدأ/خبر، اسم كان، خبر إنّ | ـون | ـان | ذو |
| Accusative: object، خبر كان، اسم إنّ، حال | ـين | ـين | ذا |
| Genitive: after a preposition، مضاف إليه، لدى/عند/مع | ـين | ـين | ذي |

| Context | ✗ wrong | ✓ correct |
|---|---|---|
| Pronoun + adjective (dialect ـين leaks in) | ✗ هم مسؤولين / ✗ نحن مستعدين | ✓ هم مسؤولون / ✓ نحن مستعدون |
| Subject | ✗ المستخدمين يستطيعون / ✗ حضر المسؤولين | ✓ المستخدمون يستطيعون / ✓ حضر المسؤولون |
| After a preposition or لدى | ✗ مع المسؤولون / ✗ لدى المطورون | ✓ مع المسؤولين / ✓ لدى المطورين |
| يوجد + dual | ✗ يوجد خيارين | ✓ يوجد خياران |
| خبر كان and sisters (accusative) | ✗ كان المشاركون متحمسون / ✗ أصبحوا قادرون / ✗ كان المشروع ناجح / ✗ أصبح الكود جاهز / ✗ ليس سهل | ✓ كان المشاركون متحمسين / ✓ أصبحوا قادرين / ✓ كان المشروع ناجحًا / ✓ أصبح الكود جاهزًا / ✓ ليس سهلًا |
| اسم إنّ (accusative), also when delayed after لدى/في/هناك/ثمة | ✗ إن المطورون / ✗ إن لدى الشركة موظفون / ✗ أن هناك خلاف | ✓ إن المطورين / ✓ إن لدى الشركة موظفين / ✓ أن هناك خلافًا |
| خبر إنّ (nominative) | ✗ إن المهندسين مجتهدين | ✓ إن المهندسين مجتهدون |
| Coordination keeps the case | ✗ التقيت المهندسين والفنيون | ✓ التقيت المهندسين والفنيين |
| ذو/ذا/ذي | ✗ مع مهندس ذو خبرة / ✗ كان ذو أثر / ✗ قضية ذو أهمية | ✓ مع مهندس ذي خبرة / ✓ كان ذا أثر / ✓ قضية ذات أهمية |
| إلا (incomplete negative: case by function) | ✗ لا يوجد إلا حلين | ✓ لا يوجد إلا حلان |
| حال | ✗ عملوا مجتمعون | ✓ عملوا مجتمعين |
| تمييز after أكثر/أقل | ✗ أكثر وضوح | ✓ أكثر وضوحًا / ✓ أقل تكلفةً |

### 3.1 Accusative alif ـًا

Indefinite accusative takes ـًا in objects and in خبر كان، حال، تمييز، adverbs (✓ أيضًا، جدًا، تقريبًا، دائمًا، غالبًا، مثلًا، أولًا، حاليًا، معًا، شكرًا).

| ✗ wrong | ✓ correct | Why |
|---|---|---|
| ✗ كتبت تقرير مفصل | ✓ كتبت تقريرًا مفصلًا | object + its adjective |
| ✗ مرةًا / ✗ ابتداءًا | ✓ مرةً / ✓ ابتداءً | no alif after ة or after اء |
| ✗ رأيت طالباتًا | ✓ رأيت طالباتٍ | feminine ـات takes kasra (ـًا fine only if ت is a root letter: ✓ أوقاتًا، أصواتًا، أبياتًا) |
| ✗ زرت مدارسًا / ✗ تجاربًا / ✗ أصدقاءً / ✗ أشياءً | ✓ زرت مدارسَ / ✓ تجاربَ / ✓ أصدقاءَ / ✓ أشياءَ | diptotes take no tanween |
| ✗ أكثرًا / ✗ أفضلًا / ✗ أحمدًا | ✓ أكثرَ تعقيدًا / ✓ أحمدَ | elatives and diptote names |
| ✗ لا شكًا | ✓ لا شكَّ / ✓ لا بدَّ | لا النافية للجنس |

Diptotes take no ـًا:
- broken plurals مفاعل، مفاعيل، فواعل، فعائل: مساجد، مشاريع، رسائل، وسائل، قواعد، تجارب، مصادر، أساليب، مناطق، معايير
- plurals in ـاء: أصدقاء، علماء، وزراء، زملاء، خبراء، رؤساء، أشياء
- أفعل adjectives and elatives: أكبر، أفضل، أكثر، أقل
- **not** diptotes (ـًا is ✓): أسماءً، أنباءً، أعداءً، أجزاءً، أبناءً، أحياءً، آراءً، أعباءً

Indefinite مبانٍ/معانٍ/ليالٍ is the strict form. Keeping the ي (مباني جديدة) is Academy-accepted: never flag it.

### 3.2 Verb endings after أن/لن/لم

| Trigger | Effect | ✗ wrong | ✓ correct |
|---|---|---|---|
| أن، لن، كي/لكي، لـ، حتى (purpose) | ن drops | ✗ لن يتمكنون / ✗ أن يكونون / ✗ كي تفهمون | ✓ لن يتمكنوا / ✓ أن يكونوا / ✓ كي تفهموا |
| لم، لمّا، لا الناهية | ن drops | ✗ لم يكتبون / ✗ لا تنسون | ✓ لم يكتبوا / ✓ لا تنسوا |
| same | final weak letter drops | ✗ لم يأتي / ✗ لم يبقى / ✗ لا تنسى / ✗ لم ينتهي / ✗ لم يرى | ✓ لم يأتِ / ✓ لم يبقَ / ✓ لا تنسَ / ✓ لم ينتهِ / ✓ لم يرَ |
| same | hollow verb shortens | ✗ لم يكون / ✗ لم يعود | ✓ لم يكن / ✓ لم يعد |
| imperative (like jussive) | same drops | ✗ ادعو (to one man) / ✗ انسى | ✓ ادعُ / ✓ انسَ |
| feminine plural ن never drops | — | — | ✓ لن يكتبن / ✓ لم يكتبن |
| لم + present only | — | ✗ لم ذهب | ✓ لم يذهب / ✓ ما ذهب |
| future negation | — | ✗ سوف لن / ✗ سوف لا | ✓ لن |
| أنْ + verb, أنّ + noun | — | ✗ أنّ يذهب | ✓ أن يذهب |
| Alif after plural و only | — | ✗ يرجوا (singular) / ✗ مهندسوا الشركة | ✓ يرجو / ✓ مهندسو الشركة / ✓ لم يذهبوا |

- Defective verbs keep the letter after أن/لن: ✓ لن يدعوَ، أن يرميَ، لن يسعى.
- ✗ لا زال يعمل (meaning "still") → ✓ ما زال يعمل / ✓ لا يزال يعمل. Strictly لا زال is a prayer (لا زلتَ بخير); it is widely tolerated in modern prose, so fix it in your own text but flag it only gently in review.
- كاد + verb without أن is preferred (✓ كاد يسقط). The form كاد أن is attested (contested): never flag it.

## 4. Idafa

| Rule | ✗ wrong | ✓ correct |
|---|---|---|
| First term: no ال, no tanween | ✗ المدير الشركة / ✗ الملف الإعدادات / ✗ الدليل المستخدم (for "user guide") | ✓ مدير الشركة / ✓ ملف الإعدادات / ✓ دليل المستخدم |
| Sound plural and dual drop ن | ✗ مهندسون الشركة / ✗ موظفين الوزارة / ✗ طرفان النزاع | ✓ مهندسو الشركة / ✓ موظفي الوزارة / ✓ طرفا النزاع |
| No alif after the construct و | ✗ مهندسوا / ✗ ذووا | ✓ مهندسو / ✓ ذوو الخبرة |
| First term shows case | ✗ قال ممثلي الدول | ✓ قال ممثلو الدول / ✓ التقى ممثلي الدول |
| Second term is genitive | ✗ رأي المختصون | ✓ رأي المختصين |
| Adjective after the whole idafa | ✗ مدير الجديد الشركة | ✓ مدير الشركة الجديد / ✓ المدير الجديد للشركة |
| Pronoun-suffixed noun + adjective: adjective definite | ✗ كتابه جديد (as a phrase) | ✓ كتابه الجديد |
| غير keeps ال off itself | ✗ المنظمات الغير حكومية | ✓ المنظمات غير الحكومية |

- Two مضاف sharing one مضاف إليه (قراءة وكتابة الدرس) is contested; ✓ قراءة الدرس وكتابته is always safe.
- Adjectival idafa with ال is grammatical: ✓ المتعدد الجنسيات.
- كافة الطلاب، نفس الكتاب، البعض، الكل: approved or contested; never flag (see approved-forms.md).

## 5. إنّ or أنّ

| Use | When | ✓ correct |
|---|---|---|
| **إنّ** | sentence start; after قال and its forms (يقول، قيل); after حيث، إذ، ألا، حتى (opening), كلا; start of a relative clause; with لام in the خبر | ✓ قال إنّ الاجتماع… / ✓ حتى إنه / ✓ إنه لصادق |
| **أنّ** | the clause stands for a noun: after other verbs (أعلن، أكّد، ذكر، أوضح، أفاد، أشار إلى، يرى، علم، تبيّن), after prepositions (بأنّ، لأنّ، رغم أنّ), after لو، لولا، ما دام | ✓ أكّد أنّ / ✓ أعلنت أنّ / ✓ لأنّ |

✗ قال أنّ → ✓ قال إنّ. ✗ أعلن إنّ → ✓ أعلن أنّ. ✗ حتى أنه → ✓ حتى إنه.

حيث أنّ is common and tolerated by some; حيث إنّ is the classical form (contested: prefer حيث إنّ, don't flag).

## 6. Relative pronouns and demonstratives

| Referent | Relative (nom. / acc.+gen.) | Near / far demonstrative |
|---|---|---|
| masc. singular | الذي | هذا / ذلك |
| fem. singular, **any non-human plural** | التي | هذه / تلك |
| masc. dual | اللذان / اللذين | هذان / هذين |
| fem. dual | اللتان / اللتين | هاتان / هاتين |
| human masc. plural | الذين (one ل, invariable) | هؤلاء / أولئك |
| human fem. plural | اللاتي / اللواتي | هؤلاء / أولئك |

| Rule | ✗ wrong | ✓ correct |
|---|---|---|
| **No relative after an indefinite noun** (English *which/that* calque) | ✗ قرأت كتابًا الذي يشرح | ✓ قرأت كتابًا يشرح / ✓ قرأت الكتاب الذي يشرح |
| Plural الذين vs dual اللذين | ✗ الطلاب اللذين | ✓ الطلاب الذين |
| Dual relative in case | ✗ رأيت الفريقين اللذان | ✓ رأيت الفريقين اللذين فازا |
| Relative matches antecedent | ✗ الطالبان الذي / ✗ الشركات الذين | ✓ الطالبان اللذان / ✓ الشركات التي |
| Demonstrative gender | ✗ هذا الطريقة / ✗ هذا الشبكة / ✗ ذلك الطريقة / ✗ هذه المشروع | ✓ هذه الطريقة / ✓ هذه الشبكة / ✓ تلك الطريقة / ✓ هذا المشروع |
| Dual demonstrative in case | ✗ في هذان / ✗ بين هاتان | ✓ في هذين / ✓ بين هاتين |
| Demonstrative with idafa follows it | ✗ هذا كتاب الطالب (for "this student's book") | ✓ كتاب الطالب هذا |

## 7. Conditionals, فاء, and related particles

| Rule | ✗ wrong | ✓ correct |
|---|---|---|
| Jussive tools (إنْ، مَن، مهما، متى، أينما، حيثما، كيفما) put present verbs of condition and answer in the jussive | ✗ إن تجتهدون تنجحون / ✗ من يسعى ينجح | ✓ إن تجتهدوا تنجحوا / ✓ من يسعَ ينجحْ / ✓ إن اجتهدتَ نجحتَ |
| إذا is not a jussive tool; usually + past | ✗ إذا تجتهدوا | ✓ إذا اجتهدتم نجحتم |
| **فاء** in the answer when it is a nominal sentence, a request (imperative, prohibition, question), ليس/عسى, or starts with ما/لن/قد/السين/سوف | ✗ إذا أردت النجاح عليك أن تجتهد / ✗ إن لم تحضر لن تفهم / ✗ إذا كان صحيحًا هذا يعني | ✓ إذا أردت النجاح فعليك أن تجتهد / ✓ إن لم تحضر فلن تفهم / ✓ إذا كان صحيحًا فهذا يعني / ✓ إن كان الأمر عاجلًا فاتصل بنا |
| Plain past or present verb answer: no فاء | — | ✓ إذا اجتهدت نجحت / ✓ إذا تأخر الرد يجب التحقق |
| أمّا … فـ: فاء obligatory | ✗ أما الخيار الثاني هو أبسط | ✓ أما الخيار الثاني فهو أبسط |
| كلّما once, answer in the past | ✗ كلما زاد الطلب كلما ارتفع السعر | ✓ كلما زاد الطلب ارتفع السعر |
| لو + past, answer often with لـ; لولا + noun (or لولا أنّ + clause) | — | ✓ لو درس لنجح / ✓ لولا الدعم لفشل المشروع |
| لمّا + past = "when", no فاء | — | ✓ لمّا وصل الوفد بدأ الاجتماع |

## 8. Prepositions (soft area)

Cairo Academy accepts one preposition standing for another (تضمين), so most "wrong preposition" claims are soft. Firm cases only:

| ✗ wrong | ✓ correct | Note |
|---|---|---|
| ✗ يتطلب إلى وقت | ✓ يتطلب الأمر وقتًا | transitive |
| ✗ حصل لـ | ✓ حصل على | — |
| ✗ بحثنا في المفتاح المفقود (meaning "searched for") | ✓ بحثنا عن المفتاح المفقود | بحث في = investigate |
| ✗ استبدل القديم بالجديد (meaning "replace old with new") | ✓ استبدل الجديد بالقديم / ✓ استعاض عن القديم بالجديد / ✓ حلّ الجديد محلّ القديم | الباء goes on the item given up |

Approved, never flag: أجاب على، أكّد على، أثّر على، تخرّج من، اعتذر عن، تحدّث مع، اتفق مع (see approved-forms.md). تعرّف على / إلى: both fine. يحتاج إلى is standard; يحتاج لـ acceptable.

## 9. Elatives and emphasis

| Rule | ✗ wrong | ✓ correct |
|---|---|---|
| أفعل + من is invariable masc. singular | ✗ هذه الطريقة سرعى من | ✓ هذه الطريقة أسرع من |
| ال and من never together | ✗ الطريقة الأسرع من | ✓ الطريقة أسرع من / ✓ الطريقة الأسرع |
| Colors and non-أفعل verbs: أكثر/أشد + noun | ✗ أستخدم من | ✓ أكثر استخدامًا / ✓ أشد حمرةً |
| Emphasis words take an agreeing pronoun | ✗ الدول كلهم | ✓ الطلاب أنفسهم / ✓ الدول كلها / ✓ المهندسون جميعهم |
| عدم + masdar; غير + adjective | ✗ عدم مسؤول | ✓ غير مسؤول / ✓ عدم الحضور |
