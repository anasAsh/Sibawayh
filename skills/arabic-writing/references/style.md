# Style: translationese, register, technical terms

Read this when a draft sounds translated or machine-written, before writing a long piece, and when choosing register or technical terms.

Markers: ✗ calque or stiff form, ✓ natural alternative.

## The density principle

**Judge density, don't ban.** Every pattern below is grammatical, and several are Academy-approved (بشكل، يُعتبر). One تمّ in a page is fine; one per sentence is translationese. Count the patterns in a paragraph: two or three are tolerable, a cluster is what makes Arabic read as translated. Rewrite the cluster, not every instance. Never present these as grammar errors.

## 1. Voice and verb structure

| Pattern | ✗ calque | ✓ natural |
|---|---|---|
| تمّ / يتمّ + masdar (the most recognisable LLM tell) | ✗ تم إنشاء الملف وتم حفظه. | ✓ أُنشئ الملف وحُفظ. / ✓ أنشأنا الملف وحفظناه. |
| | ✗ يتم استخدام هذه الدالة لـ… | ✓ تُستخدم هذه الدالة لـ… / ✓ نستخدم هذه الدالة لـ… |
| Passive + من قِبَل / من طرف / بواسطة + agent | ✗ تمت الموافقة على الطلب من قبل المدير. | ✓ وافق المدير على الطلب. |
| | ✗ نُشر التقرير من قبل الفريق. | ✓ نشر الفريق التقرير. |
| قام بـ / يقوم بـ + masdar | ✗ قم بتثبيت الحزمة ثم قم بتشغيل الأمر. | ✓ ثبّت الحزمة ثم شغّل الأمر. |
| | ✗ قام بتحليل البيانات. | ✓ حلّل البيانات. |
| يمكنك + verb, repeated | ✗ يمكنك فتح الملف ثم يمكنك تعديله. | ✓ افتح الملف وعدّله. |
| يلعب دورًا (contested, widely used: thin it out, don't correct it) | ✗ يلعب دورًا حاسمًا | ✓ يؤدي دورًا حاسمًا / ✓ له أثر كبير في / ✓ يُسهم في |
| يأخذ مكانًا (takes place) | ✗ يأخذ الاجتماع مكانًا غدًا | ✓ يُعقد الاجتماع غدًا / ✓ يجري / ✓ يقع |
| يأخذ بعين الاعتبار | ✗ يأخذ بعين الاعتبار | ✓ يراعي / ✓ يأخذ في الحسبان |
| يلقي نظرة | ✗ دعنا نلقي نظرة على… | ✓ لننظر في… / ✓ نستعرض… |
| يصنع فرقًا | ✗ يصنع فرقًا | ✓ يُحدث فرقًا / ✓ يغيّر |
| أعلن عن | ✗ أعلنت الشركة عن إصدار جديد | ✓ أعلنت الشركة إصدارًا جديدًا |

Classical Arabic uses the passive when the agent is **not** named. If you name the agent, use the active voice. With a known agent in instructions, use the imperative or نحن.

## 2. كـ "as a", and -ly adverbs

| Pattern | ✗ calque | ✓ natural |
|---|---|---|
| كـ for "in the role of" (كـ is for likeness) | ✗ يعمل كمهندس | ✓ يعمل مهندسًا |
| | ✗ استخدم Redis كذاكرة مؤقتة | ✓ استخدم Redis ذاكرةً مؤقتة / ✓ استخدم Redis بوصفه ذاكرة مؤقتة |
| بشكل / بطريقة + adjective for English -ly (approved; a smell only in clusters) | ✗ يعمل بشكل صحيح وبشكل فعال ويتحسن بشكل كبير | ✓ يعمل كما ينبغي وبفاعلية، ويتحسن الأداء تحسنًا كبيرًا |
| بشكل عام | ✗ بشكل عام (repeated) | ✓ عمومًا / ✓ بوجه عام |
| واحد من أهم / واحدة من أكثر | ✗ واحدة من أهم المشكلات | ✓ من أهم المشكلات |
| ليس فقط… بل أيضًا | ✗ ليس فقط سريعًا، بل أيضًا آمن | ✓ ليس سريعًا فحسب، بل آمن أيضًا / ✓ لا يقتصر على السرعة، بل يشمل الأمان |

## 3. Connectors and sentence openers

| Pattern | ✗ calque or filler | ✓ natural |
|---|---|---|
| بالتالي / وبالتالي | ✗ وبالتالي يفشل البناء | ✓ لذا يفشل البناء / ✓ ومن ثَمّ / ✓ فيفشل البناء / ✓ وعليه |
| "It's worth noting" | ✗ من الجدير بالذكر أن… / ✗ تجدر الإشارة إلى أن… / ✗ من المهم ملاحظة أن… | ✓ state the fact directly |
| Cleft or pronoun-first | ✗ إنه من المهم أن… | ✓ من المهم أن… (or delete it) |
| هناك + noun + التي (the structure, not العديد من, is the problem) | ✗ هناك العديد من الطرق التي يمكن… | ✓ ثمة طرق عدة لـ… / ✓ يمكن… بطرق عدة |
| بكلمات أخرى | ✗ بكلمات أخرى | ✓ أي / ✓ بعبارة أخرى |
| في نهاية اليوم | ✗ في نهاية اليوم (meaning "ultimately") | ✓ في المحصلة |
| على الجانب الآخر | ✗ على الجانب الآخر (meaning "on the other hand") | ✓ في المقابل / ✓ من جهة أخرى |
| وأخيرًا وليس آخرًا | ✗ وأخيرًا وليس آخرًا | ✓ وأخيرًا |
| على حدٍّ سواء: only after a coordinated pair | ✗ مفيد للمبتدئين على حد سواء | ✓ للمبتدئين والمحترفين على حد سواء |
| من خلال for every "through/by" | ✗ من خلال استخدام الأمر | ✓ باستخدام الأمر / ✓ عبر / ✓ بـ |
| بالنسبة لـ | ✗ بالنسبة لي، أفضّل… | ✓ أفضّل… / ✓ أما أنا فأفضّل… |

Optional elegant forms (the approved form is also correct; never correct a user to these):
- ✓ في الوقت نفسه instead of ✓ في نفس الوقت
- ✓ بالطريقة نفسها instead of ✓ بنفس الطريقة
- ✓ الشيء ذاته instead of ✓ ذات الشيء

### 3.1 Stock paragraph openers

علاوة على ذلك، بالإضافة إلى ذلك، ومع ذلك، في الختام، وختامًا are standard MSA, not errors. The problem is the English essay template: one at the head of every paragraph.

| ✗ template | ✓ natural |
|---|---|
| ✗ "علاوة على ذلك، …" then "بالإضافة إلى ذلك، …" then "في الختام، …" opening consecutive paragraphs | ✓ vary or drop them; link clauses with و، فـ، ثم، بل، إذ، حيث |
| ✗ في العصر الحديث… / ✗ في عالم اليوم سريع التغير… / ✗ في الآونة الأخيرة… as a scene-setting first line | ✓ start with the point |
| ✗ formulaic closing paragraph (في الختام، يمكن القول إن…) | ✓ end when the content ends |

Other machine-translation idioms to thin out: يمهّد الطريق، يسلّط الضوء على، رحلة (for any process), غوص عميق (deep dive). Hedging stacks (من المهم، من الضروري، يُعتقد أن) also count toward density.

## 4. Word order, determination, sentence shape

| Pattern | ✗ calque | ✓ natural |
|---|---|---|
| Stream of noun-first sentences | ✗ الشركة أعلنت… المستخدمون لاحظوا… الفريق قرر… | ✓ أعلنت الشركة… ولاحظ المستخدمون… وقرر الفريق… (noun-first is fine for topic, contrast, headings) |
| ال on the first term of an idafa | ✗ الملف الإعدادات / ✗ الدليل المستخدم | ✓ ملف الإعدادات / ✓ دليل المستخدم |
| Stacked noun compounds | ✗ نظام إدارة قاعدة بيانات علائقية مفتوح المصدر | ✓ split it: نظام مفتوح المصدر لإدارة قواعد البيانات العلائقية |
| Repeated possessives (English "your") | ✗ افتح ملفك ثم احفظ ملفك في مجلدك. | ✓ افتح الملف واحفظه في المجلد. |
| Repeated noun where a pronoun works | ✗ ثبّت الحزمة ثم حدّث الحزمة | ✓ ثبّت الحزمة ثم حدّثها |
| Comma chains (English clause splicing) | ✗ نفتح الملف، نعدّله، نحفظه، نغلقه، ننشره | ✓ نفتح الملف ونعدّله، ثم نحفظه وننشره. |
| Endless و-chains | ✗ one 80-word sentence joined by و | ✓ end the sentence; aim under ~60 words and ≤ 4 commas |

Also vary sentence and paragraph length; don't turn every answer into bullets.

## 5. Register

- **Default: semi-formal MSA** (فصحى معاصرة): correct grammar, modern vocabulary, short sentences, no ornament. The register of good tech journalism and Arabic product docs.
- For assistant replies: direct imperatives (✓ افتح، شغّل، ثبّت), first-person plural for the writer (✓ نستخدم، سنضيف), short sentences.
- **One register per reply.** Dialect only if the user writes casually in dialect or asks for it; technical content usually stays MSA. An MSA reply to a dialect question is normal; dialect words inside an MSA reply read as errors.

| ✗ avoid in MSA | ✓ use |
|---|---|
| ✗ عشان | ✓ لأنّ / ✓ لكي |
| ✗ بس (meaning "only" / "but") | ✓ فقط / ✓ لكن |
| ✗ كمان | ✓ أيضًا |
| ✗ هيك / ✗ زي | ✓ هكذا / ✓ مثل |
| ✗ دلوقتي / ✗ هلق | ✓ الآن |
| ✗ إيش / ✗ شو | ✓ ماذا / ✓ ما |
| ✗ ده / ✗ دي / ✗ اللي | ✓ هذا / ✓ هذه / ✓ الذي، التي |
| ✗ بيعمل (بـ on present verbs), ✗ هيعمل / حيعمل | ✓ يعمل / ✓ سيعمل |
| ✗ ـين plural everywhere (المستخدمين as subject) | ✓ ـون in the nominative (grammar.md §3) |
| ✗ bureaucratic padding: نحيطكم علمًا، يسرّنا إفادتكم، ليكن في علمكم | ✓ say it plainly |
| ✗ ornate rarities in casual tech help (حريّ بالذكر، saj'-like padding) | ✓ plain modern words |

- Addressee: masculine generic for an unknown user; feminine if the user is known to be female. Never switch mid-reply or mix forms (✗ افعل/ي).
- Keep one spelling convention, one digit system, one quote style throughout (orthography.md).

## 6. Technical terms

1. Use the established Arabic term when one exists and is used; add the English in parentheses **on first mention only**: ✓ «واجهة برمجة التطبيقات (API)», then «الواجهة» or «API» consistently.
2. Keep in Latin script, in backticks: identifiers, commands, file names, library names, flags, anything the user must type. ✗ «بايثون» in a command or code context. Brand names usually stay Latin in tech text; pick one form per reply.
3. Transliterate only established forms whose Arabic coinage isn't used: ✓ بروتوكول، خوارزمية، تقنية، برمجيات، إنترنت.
4. Don't invent a translation. Unsure → English in parentheses.
5. No Arabic morphology on English words: ✗ الـ commits، ✗ deployات → ✓ «الإيداعات (commits)» / ✓ «عمليات commit».
6. No stray English words in Arabic prose outside parentheses or code (language confusion is a documented LLM failure).

Common equivalents (glossary.md has more):

| English | Arabic | English | Arabic |
|---|---|---|---|
| file / folder | ملف / مجلد | server / client | خادم / عميل |
| database / query | قاعدة بيانات / استعلام | function | دالّة |
| variable / constant | متغير / ثابت | array / string | مصفوفة / سلسلة نصية |
| library / framework | مكتبة / إطار عمل | package / dependency | حزمة / اعتمادية |
| repository / branch / merge | مستودع / فرع / دمج | pull request | طلب دمج (pull request) |
| bug / debugging | خطأ برمجي، علّة / تصحيح الأخطاء، تنقيح | deploy | نشر |
| cache / container | ذاكرة تخزين مؤقت / حاوية | browser / cloud | متصفح / السحابة |
| machine learning / AI | تعلّم الآلة / الذكاء الاصطناعي | model / training | نموذج / تدريب |
| settings / configuration | إعدادات / تهيئة | install / update | تثبيت / تحديث |
| token (LLM) | رمز (token) | prompt | موجِّه (prompt), no settled term |
