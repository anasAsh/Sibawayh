# Common errors

Read this when reviewing Arabic text (yours or the user's) for the frequent errors, and before telling anyone that a form is wrong.

Only two kinds of item are listed:
- **firm**: an error by near-consensus. Fix it.
- **style**: grammatical but calqued, redundant or wordy. Suggest, don't insist; judge density (style.md).

Approved forms (approved-forms.md) and contested forms (طالما، بينما، سويًّا، كافة الطلاب …) are **not** errors and are deliberately absent from this file. If a form is not here and not clearly ungrammatical, leave it alone.

## 1. Orthography (all firm)

| ✗ wrong | ✓ right | Status | Note |
|---|---|---|---|
| ✗ الى، اذا، انشاء، اكثر | ✓ إلى، إذا، إنشاء، أكثر | firm | missing hamza on همزة القطع; the most common error in web text |
| ✗ ان (particle)، او، انا، الا | ✓ إنّ/أنّ/إن/أن، أو، أنا، إلا | firm | same rule |
| ✗ إستخدام، إنتقال، إستيراد | ✓ استخدام، انتقال، استيراد | firm | hamzat al-wasl in masdars of 5- and 6-letter verbs |
| ✗ إسم، إبن، إثنان، إمرأة | ✓ اسم، ابن، اثنان، امرأة | firm | the wasl nouns |
| ✗ الإطلاع | ✓ الاطّلاع | firm | masdar of اطّلع (wasl) |
| ✗ مدرسه، الشبكه، الجامعه | ✓ مدرسة، الشبكة، الجامعة | firm | ة/ه at word end |
| ✗ الذى، فى، التى | ✓ الذي، في، التي | firm | final ي is dotted in pan-Arab MSA |
| ✗ علي البيت، الي المدرسة | ✓ على البيت، إلى المدرسة | firm | ى/ي confusion on particles |
| ✗ استنفاذ | ✓ استنفاد | firm | root ن ف د (run out) |
| ✗ اضطرد | ✓ اطّرد | firm | — |
| ✗ البرئ، شيئ، شئ | ✓ البريء، شيء | firm | final hamza after a long vowel or sukun sits on the line |
| ✗ لاكن، هاذا، ذالك، هاؤلاء | ✓ لكن، هذا، ذلك، هؤلاء | firm | silent alif is not written |
| ✗ إنشاء الله (meaning "God willing") | ✓ إن شاء الله | firm | إنشاء means "creation" |
| ✗ على حدى، على حدا | ✓ على حِدَة | firm | — |
| ✗ من ما، عن ما | ✓ ممّا، عمّا | firm | joined with shadda |
| ✗ لاسيما | ✓ لا سيّما | firm | two words |
| ✗ عادتاً، خاصتاً، نتيجتاً | ✓ عادةً، خاصةً، نتيجةً | firm | ة takes tanween with no alif |
| ✗ تفائل، تشائم، قرائة، يتسائل | ✓ تفاؤل، تشاؤم، قراءة، يتساءل | firm | middle hamza seat |
| ✗ شاطيء، مباديء | ✓ شاطئ، مبادئ | firm | final hamza after kasra sits on ئ |
| ✗ ذهبو، لم يكتبو | ✓ ذهبوا، لم يكتبوا | firm | alif after the plural و of a verb |
| ✗ مهندسوا الشركة | ✓ مهندسو الشركة | firm | no alif after a construct plural noun |

Consistency, not errors: the Egyptian ئ spelling of مسؤول, the alif spelling of مئة, and tanween written on the alif are each valid regional variants; mixing variants in one text is the problem. House defaults: ✓ مسؤول، مئة، ـًا (orthography.md).

## 2. Morphology and agreement (firm; where LLMs fail most)

| ✗ wrong | ✓ right | Status | Note |
|---|---|---|---|
| ✗ ثلاث كتب | ✓ ثلاثة كتب | firm | 3–10 take the opposite gender of the singular noun |
| ✗ ثلاثة صفحات | ✓ ثلاث صفحات | firm | same |
| ✗ أحد عشر خطوة | ✓ إحدى عشرة خطوةً | firm | 11–12: both parts agree |
| ✗ خمسة عشر ملفات | ✓ خمسة عشر ملفًا | firm | 11–99 take an accusative singular noun |
| ✗ ثلاثة ملف | ✓ ثلاثة ملفات | firm | 3–10 take a genitive plural |
| ✗ عشرة ملفًا | ✓ عشرة ملفات | firm | same |
| ✗ أحد الطالبات | ✓ إحدى الطالبات | firm | أحد/إحدى agree with the noun |
| ✗ بضع أيام | ✓ بضعة أيام | firm | بضع/بضعة follow the 3–10 rule |
| ✗ هذا الشبكة، ذلك الطريقة | ✓ هذه الشبكة، تلك الطريقة | firm | demonstrative gender |
| ✗ الملفات الذين | ✓ الملفات التي | firm | non-human plural → feminine singular |
| ✗ الملفات موجودون | ✓ الملفات موجودة | firm | same |
| ✗ الخيارات المتاحون | ✓ الخيارات المتاحة | firm | same |
| ✗ ذهبوا الطلاب | ✓ ذهب الطلاب | firm | verb before its plural subject is singular |
| ✗ المستخدمين يستطيعون | ✓ المستخدمون يستطيعون | firm | nominative ـون (dialect ـين leaks in) |
| ✗ يوجد خيارين | ✓ يوجد خياران | firm | nominative dual ـان |
| ✗ إن المطورون | ✓ إن المطورين | firm | accusative after إنّ |
| ✗ لم يكتبون | ✓ لم يكتبوا | firm | ن drops after لم/لن/أن/لا الناهية |
| ✗ لا تنسى (prohibition) | ✓ لا تنسَ | firm | weak letter drops in the jussive |
| ✗ لم يأتي، لم يكون | ✓ لم يأتِ، لم يكن | firm | same; hollow verbs shorten |
| ✗ كان المشروع ناجح | ✓ كان المشروع ناجحًا | firm | خبر كان is accusative |
| ✗ أصبح الكود جاهز | ✓ أصبح الكود جاهزًا | firm | same |
| ✗ أخين | ✓ أخوين | firm | dual of أخ restores the و |
| ✗ قرأت كتابًا الذي يشرح | ✓ قرأت كتابًا يشرح | firm | no relative pronoun after an indefinite noun |
| ✗ قال أنّ | ✓ قال إنّ | firm | إنّ after قال |
| ✗ الطلاب اللذين | ✓ الطلاب الذين | firm | plural الذين has one ل |

## 3. Particles and fixed expressions

| ✗ wrong | ✓ right | Status | Note |
|---|---|---|---|
| ✗ سوف لن، سوف لا | ✓ لن، لا | firm | لن alone negates the future |
| ✗ لا زال يعمل (meaning "still") | ✓ ما زال يعمل، لا يزال يعمل | firm | strictly a prayer formula (لا زلتَ بخير); widely tolerated, so flag gently |
| ✗ كما وأن | ✓ كما أن | firm | two conjunctions don't stack |
| ✗ ما من أحد إلا ويعرف | ✓ ما من أحد إلا يعرف | firm | the و after إلا is redundant |
| ✗ حتى أنه | ✓ حتى إنه | firm | حتى opens a sentence here, so إنّ |
| ✗ كلما درست كلما فهمت | ✓ كلما درست فهمت | firm | كلما once |
| ✗ إلى عند | ✓ إلى | firm | redundant |
| ✗ عدا عن ذلك | ✓ فضلًا عن ذلك | firm | — |
| ✗ لأول وهلة | ✓ أولَ وهلة | style | — |
| ✗ كم عدد الملفات؟ | ✓ كم ملفًّا؟ / ✓ ما عدد الملفات؟ | style | redundant |
| ✗ وأخيرًا وليس آخرًا | ✓ وأخيرًا | style | calque of "last but not least" |
| ✗ ليس فقط… بل أيضًا | ✓ لا… فحسب، بل… | style | calque of "not only… but also" |
| ✗ بالنسبة لي | ✓ لي / ✓ أما أنا فـ… | style | redundant |
| ✗ أما بالنسبة إلى | ✓ أما… فـ | style | redundant |
