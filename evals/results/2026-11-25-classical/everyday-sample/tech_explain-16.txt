## ما الاستدعاء الذاتي؟

الاستدعاء الذاتي (Recursion) أن تستدعي الدالة نفسها لتحل نسخة أصغر من المسألة ذاتها، وتكرر ذلك حتى تبلغ حالة بسيطة تعرف جوابها مباشرة.

تقوم كل دالة من هذا النوع على ركنين:

- **الحالة الأساسية (Base case):** الشرط الذي يوقف الاستدعاء ويعيد قيمة معروفة.
- **الحالة التعاودية (Recursive case):** الخطوة التي تستدعي فيها الدالة نفسها بمدخل أصغر، فتقترب من الحالة الأساسية.

## مثال: حساب المضروب

المضروب (Factorial) هو حاصل ضرب الأعداد الصحيحة من 1 إلى العدد المطلوب، ورمزه `n!`. فمثلًا `5! = 5 × 4 × 3 × 2 × 1 = 120`.

لاحظ أن `5!` تساوي `5 × 4!`، أي إن المسألة تتضمن نسخة أصغر من نفسها. ومن هنا يأتي التعريف:

- الحالة الأساسية: `0! = 1`
- الحالة التعاودية: `n! = n × (n - 1)!`

والدالة تكاد تطابق هذا التعريف:

```javascript
function factorial(n) {
  if (!Number.isInteger(n) || n < 0) {
    throw new RangeError("يجب أن يكون العدد صحيحًا غير سالب");
  }

  // الحالة الأساسية
  if (n === 0) return 1;

  // الحالة التعاودية
  return n * factorial(n - 1);
}

console.log(factorial(5)); // 120
```

## كيف تُنفَّذ الدالة؟

حين تستدعي `factorial(4)` ينتظر كل استدعاء نتيجة الاستدعاء الذي يليه، ثم تعود النتائج بالترتيب العكسي:

```text
factorial(4)
= 4 * factorial(3)
= 4 * (3 * factorial(2))
= 4 * (3 * (2 * factorial(1)))
= 4 * (3 * (2 * (1 * factorial(0))))
= 4 * (3 * (2 * (1 * 1)))
= 4 * (3 * (2 * 1))
= 4 * (3 * 2)
= 4 * 6
= 24
```

يحفظ المحرك الاستدعاءات المنتظرة في مكدس الاستدعاءات (Call stack): يضيف كل استدعاء جديد إلى أعلى المكدس، ثم يزيله حين يعيد نتيجته.

## تنبيهات مهمة

- **الحالة الأساسية ضرورية:** من دونها تستمر الاستدعاءات حتى يمتلئ المكدس، فيظهر في بيئة `Node.js` مثلًا الخطأ `RangeError: Maximum call stack size exceeded`.
- **عمق الاستدعاء محدود:** قد يمتلئ المكدس مع المدخلات الكبيرة جدًا حتى إن كانت الدالة صحيحة، والحلقة (Loop) أنسب في هذه الحالة.
- **دقة الأعداد محدودة:** لا يضمن النوع `Number` دقة الأعداد الصحيحة فوق `Number.MAX_SAFE_INTEGER`، وأكبر مضروب يقع ضمن هذا الحد هو `18!`. استعمل النوع `BigInt` لما هو أكبر.

وهذه نسخة بالحلقة للمقارنة، من دون التحقق من المدخل:

```javascript
function factorialLoop(n) {
  let result = 1;
  for (let i = 2; i <= n; i++) {
    result *= i;
  }
  return result;
}
```

يناسب الاستدعاء الذاتي المسائل التي تتكرر بنيتها داخلها، مثل التنقل في الأشجار والمجلدات المتداخلة. أما المضروب فالحلقة أوفر له في الذاكرة، لكنه مثال واضح لفهم الفكرة.
