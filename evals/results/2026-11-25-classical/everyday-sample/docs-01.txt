````markdown
# مكتبة `package_name`

مكتبة بايثون (Python) تحوّل ملفات القيم المفصولة بفواصل (CSV) إلى صيغة تبادل البيانات (JSON). تقرأ المكتبة الصف الأول من الملف على أنه أسماء الأعمدة، ثم تحوّل كل صف بعده إلى كائن (object) مفاتيحه تلك الأسماء، وتجمع الكائنات في مصفوفة (array) واحدة.

تفيدك المكتبة حين تريد تمرير بيانات جدول إلى تطبيق ويب، أو تجهيزها لواجهة برمجة تطبيقات (API)، من غير أن تكتب شيفرة التحويل بنفسك في كل مشروع.

## التثبيت

ثبّت المكتبة بمدير الحزم `pip`:

```bash
pip install package_name
```

## الاستخدام السريع

لنفترض أن لديك ملفًا باسم `users.csv` يحوي البيانات الآتية:

```csv
name,city
سارة,الرياض
عمر,القاهرة
```

استدعِ الدالة `convert`، ومرّر إليها مسار الملف الأصلي ومسار الملف الناتج:

```python
from package_name import convert

convert("users.csv", "users.json")
```

ستجد في الملف `users.json` النتيجة الآتية:

```json
[
  {"name": "سارة", "city": "الرياض"},
  {"name": "عمر", "city": "القاهرة"}
]
```
````

لم أجد شيفرة المكتبة في مجلد العمل، لذلك افترضت اسم الحزمة `package_name` والدالة `convert` وطريقة التحويل وشكل الناتج. عدّلها لتطابق مكتبتك قبل النشر. ولم أحفظ النص في ملف.
