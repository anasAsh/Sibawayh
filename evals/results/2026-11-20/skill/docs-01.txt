````markdown
# مكتبة `csv2json`

مكتبة بايثون خفيفة تحوّل ملفات CSV إلى صيغة JSON بسطر واحد من الشيفرة. تقرأ المكتبة الملف، وتستخرج أسماء الأعمدة من السطر الأول، ثم تُخرج قائمة من الكائنات يمثّل كلٌّ منها صفًّا واحدًا. وتدعم الترميزات المختلفة مثل UTF-8، والفواصل المخصّصة، والملفات الكبيرة التي لا تتّسع لها الذاكرة دفعةً واحدة.

## المزايا

- واجهة بسيطة: دالّة واحدة تكفي لمعظم الحالات.
- دعم كامل للنصوص العربية وسائر اللغات.
- قراءة تدريجية للملفات الكبيرة دون تحميلها كاملةً في الذاكرة.
- أداة لسطر الأوامر (CLI) للتحويل المباشر من الطرفية.
- لا تعتمد على أي حزمة خارجية.

## التثبيت

تتطلّب المكتبة الإصدار 3.9 من بايثون أو ما بعده. ثبّتها باستخدام `pip`:

```bash
pip install csv2json
```

أو ثبّت أحدث نسخة من المستودع مباشرة:

```bash
pip install git+https://github.com/example/csv2json.git
```

## الاستخدام السريع

### التحويل من ملف إلى ملف

```python
from csv2json import convert

convert("data.csv", "data.json")
```

### الحصول على النتيجة بوصفها كائنات بايثون

```python
from csv2json import load

rows = load("data.csv", delimiter=";", encoding="utf-8")
print(rows[0])
# {'name': 'سارة', 'city': 'عمّان', 'age': '29'}
```

### التحويل من سطر الأوامر

```bash
csv2json data.csv -o data.json --indent 2
```

لمزيد من الخيارات، شغّل الأمر `csv2json --help`.
````
