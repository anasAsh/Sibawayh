# ما هو ترميز Big O؟

ترميز **Big O** هو طريقة رياضية لوصف **كيف يزداد زمن تنفيذ الخوارزمية (أو استهلاكها للذاكرة) كلما كبر حجم المدخلات**، ويُرمز لحجم المدخلات عادةً بالحرف `n`.

هو لا يقيس الزمن بالثواني، بل يقيس **معدل النمو**. لذلك نتجاهل الثوابت والحدود الصغيرة: خوارزمية تنفّذ `3n + 5` عملية تُكتب ببساطة `O(n)`. وغالبًا يُستخدم لوصف **أسوأ حالة** ممكنة.

---

## O(1) — زمن ثابت

عدد العمليات لا يتغير مهما كان حجم المدخلات.

```python
def first_element(items):
    return items[0]
```

سواء احتوت القائمة على 10 عناصر أو 10 ملايين، الوصول إلى العنصر الأول يتم بخطوة واحدة.

**مثال من الواقع:** فتح كتاب على صفحة تعرف رقمها مسبقًا.

---

## O(n) — زمن خطي

عدد العمليات يزداد بنفس نسبة ازدياد المدخلات: إذا تضاعف `n` تضاعف الزمن.

```python
def contains(items, target):
    for item in items:
        if item == target:
            return True
    return False
```

في أسوأ حالة (العنصر غير موجود أو في آخر القائمة) نمرّ على جميع العناصر، أي `n` عملية مقارنة.

**مثال من الواقع:** البحث عن اسم في قائمة غير مرتبة بقراءتها سطرًا سطرًا.

---

## O(n²) — زمن تربيعي

عدد العمليات يتناسب مع مربع حجم المدخلات: إذا تضاعف `n` أصبح الزمن أربعة أضعاف. يظهر عادةً مع الحلقات المتداخلة.

```python
def has_duplicates(items):
    for i in range(len(items)):
        for j in range(i + 1, len(items)):
            if items[i] == items[j]:
                return True
    return False
```

كل عنصر يُقارن بباقي العناصر، فيكون عدد المقارنات قرابة `n²/2`، ونكتبها `O(n²)` بعد إهمال الثابت.

**مثال من الواقع:** في قاعة فيها `n` شخص، يصافح كل شخص جميع الآخرين.

---

## مقارنة سريعة

| حجم المدخلات `n` | O(1) | O(n) | O(n²) |
|---|---|---|---|
| 10 | 1 | 10 | 100 |
| 1,000 | 1 | 1,000 | 1,000,000 |
| 1,000,000 | 1 | 1,000,000 | 1,000,000,000,000 |

الفرق يكاد لا يُلاحظ مع المدخلات الصغيرة، لكنه يصبح حاسمًا مع المدخلات الكبيرة: خوارزمية `O(n²)` قد تحتاج ساعات لمعالجة بيانات تنهيها خوارزمية `O(n)` في أقل من ثانية.
