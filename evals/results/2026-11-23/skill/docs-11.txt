# توثيق واجهة الطقس

تتيح واجهة برمجة التطبيقات (API) هذه معرفة حالة الطقس الحالية في مدينة تحددها، وتُرجع النتيجة بصيغة جيسون (JSON). العنوان `api.example.com` والمفتاح وأسماء الحقول قيم افتراضية وضعتُها للتوضيح، فاستبدل بها قيم خدمتك الفعلية.

## العنوان الأساسي

```
https://api.example.com/v1
```

## المصادقة

أرسل مفتاحك في الترويسة `X-API-Key` مع كل طلب. يُرفض أي طلب بلا مفتاح صالح بالرمز `401`.

## نقطة النهاية: حالة الطقس الحالية

```
GET /weather
```

تُرجع حالة الطقس الحالية في المدينة المطلوبة.

### معاملات الاستعلام

| المعامل | النوع | مطلوب | الوصف |
|---|---|---|---|
| `city` | نص | نعم | اسم المدينة بالعربية أو الإنجليزية، مثل `الرياض` أو `Riyadh`. |
| `country` | نص | لا | رمز الدولة المكوّن من حرفين، مثل `SA`. يفيد حين يتكرر اسم المدينة في أكثر من دولة. |
| `units` | نص | لا | نظام الوحدات: `metric` (مئوية وكم/س) أو `imperial` (فهرنهايت وميل/س). القيمة الافتراضية `metric`. |
| `lang` | نص | لا | لغة الوصف النصي للطقس: `ar` أو `en`. القيمة الافتراضية `ar`. |

### مثال للطلب

```bash
curl -G "https://api.example.com/v1/weather" \
  -H "X-API-Key: YOUR_API_KEY" \
  --data-urlencode "city=الرياض" \
  -d "country=SA" \
  -d "units=metric" \
  -d "lang=ar"
```

### مثال للاستجابة

عند نجاح الطلب تعود الاستجابة بالرمز `200`:

```json
{
  "city": "الرياض",
  "country": "SA",
  "observed_at": "2026-11-23T09:30:00Z",
  "units": "metric",
  "temperature": 24.5,
  "feels_like": 23.8,
  "humidity": 32,
  "wind_speed": 14.2,
  "condition": "clear",
  "description": "سماء صافية"
}
```

### حقول الاستجابة

| الحقل | النوع | الوصف |
|---|---|---|
| `city` | نص | اسم المدينة. |
| `country` | نص | رمز الدولة المكوّن من حرفين. |
| `observed_at` | نص | وقت الرصد بالتوقيت العالمي المنسق وبصيغة `ISO 8601`. |
| `units` | نص | نظام الوحدات المستخدم في القيم. |
| `temperature` | عدد | درجة الحرارة. |
| `feels_like` | عدد | درجة الحرارة المحسوسة. |
| `humidity` | عدد | الرطوبة النسبية، من 0 إلى 100. |
| `wind_speed` | عدد | سرعة الرياح. |
| `condition` | نص | رمز ثابت لحالة الطقس يصلح للاستخدام في الشيفرة: `clear` أو `clouds` أو `rain` أو `snow` أو `storm` أو `fog` أو `dust`. |
| `description` | نص | وصف مقروء لحالة الطقس باللغة المحددة في `lang`. |

### الأخطاء

تعود الأخطاء كلها بالبنية نفسها:

```json
{
  "error": {
    "code": "city_not_found",
    "message": "لم نعثر على مدينة باسم «الرياظ». تحقق من الإملاء أو أضف المعامل country."
  }
}
```

| رمز الحالة | قيمة `code` | السبب |
|---|---|---|
| `400` | `invalid_parameter` | المعامل `city` مفقود، أو قيمة أحد المعاملات غير صالحة. |
| `401` | `unauthorized` | المفتاح مفقود أو غير صالح. |
| `404` | `city_not_found` | لا توجد مدينة بالاسم المطلوب. |
| `429` | `rate_limited` | تجاوزت الحد المسموح به من الطلبات. انتظر المدة المذكورة في الترويسة `Retry-After` ثم أعد المحاولة. |
| `500` | `server_error` | خطأ في الخادم. أعد المحاولة بعد قليل. |

لم أحفظ التوثيق في المستودع، فإن أردته ملفًّا مثل `README.md` أو بصيغة مواصفة الواجهات المفتوحة (OpenAPI) فأخبرني.
