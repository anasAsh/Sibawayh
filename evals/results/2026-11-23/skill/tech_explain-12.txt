## ما ترميز O الكبير؟

ترميز O الكبير (Big O notation) طريقة رياضية تصف كيف يزداد زمن تنفيذ الخوارزمية، أو مقدار الذاكرة التي تستهلكها، كلما كبر حجم المدخلات، ونرمز إلى هذا الحجم بالحرف `n`.

لا يقيس هذا الترميز الزمن بالثواني، لأن الثواني تختلف من جهاز إلى آخر، وإنما يقيس **معدل النمو**: إذا تضاعف حجم المدخلات، فكم يزداد عدد العمليات؟ ويصف في العادة أسوأ حالة ممكنة، ويهمل الثوابت والحدود الصغيرة؛ فالخوارزمية التي تنفذ `3n + 5` عملية تُكتب `O(n)`.

## التعقيد الثابت `O(1)`

يبقى عدد العمليات ثابتًا مهما كبر حجم المدخلات. مثال ذلك الوصول إلى عنصر في مصفوفة عن طريق فهرسه:

```python
def first_item(items):
    return items[0]
```

سواء احتوت القائمة على 10 عناصر أو على مليون عنصر، تنفذ الدالة خطوة واحدة.

## التعقيد الخطي `O(n)`

يزداد عدد العمليات بنسبة ازدياد حجم المدخلات نفسها: إذا تضاعف الحجم تضاعف الزمن. مثال ذلك البحث عن قيمة في قائمة غير مرتبة:

```python
def contains(items, target):
    for item in items:
        if item == target:
            return True
    return False
```

في أسوأ حالة، تكون القيمة في آخر القائمة أو غير موجودة، فتمر الحلقة على العناصر كلها، أي تنفذ `n` خطوة.

## التعقيد التربيعي `O(n²)`

يتناسب عدد العمليات مع مربع حجم المدخلات: إذا تضاعف الحجم صار الزمن أربعة أضعافه. يظهر هذا التعقيد غالبًا في الحلقات المتداخلة، مثل مقارنة كل عنصر بسائر العناصر بحثًا عن قيمة مكررة:

```python
def has_duplicate(items):
    for i in range(len(items)):
        for j in range(i + 1, len(items)):
            if items[i] == items[j]:
                return True
    return False
```

تدور الحلقة الخارجية `n` مرة، وتدور الحلقة الداخلية في كل مرة نحو `n` مرة، فيكون المجموع قرابة `n × n` عملية.

## مقارنة سريعة

| حجم المدخلات `n` | عمليات `O(1)` | عمليات `O(n)` | عمليات `O(n²)` |
|---|---|---|---|
| عشرة | 1 | 10 | 100 |
| ألف | 1 | 1,000 | 1,000,000 |
| مليون | 1 | 1,000,000 | 1,000,000,000,000 |

يبيّن الجدول سبب أهمية هذا الترميز: الفرق بين الخوارزميات يكاد لا يُلحظ مع المدخلات الصغيرة، لكنه يصبح حاسمًا مع المدخلات الكبيرة؛ فالخوارزمية التربيعية التي تعالج ألف عنصر في لحظة قد تحتاج إلى أيام لمعالجة مليون عنصر.
