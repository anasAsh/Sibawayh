## مفهوم الاستدعاء الذاتي

**الاستدعاء الذاتي (recursion)** أسلوب برمجي تستدعي فيه الدالة نفسها، فتحل المسألة بتحويلها إلى نسخة أصغر من المسألة ذاتها، وتكرر ذلك حتى تصل إلى حالة بسيطة يُعرف جوابها مباشرة.

تتكون كل دالة من هذا النوع من جزأين:

- **حالة التوقف (base case):** الشرط الذي تكف عنده الدالة عن استدعاء نفسها. إذا غاب هذا الشرط استمر الاستدعاء بلا نهاية.
- **الخطوة الذاتية (recursive case):** استدعاء الدالة نفسها بمُدخل أصغر يقترب من حالة التوقف.

## مثال: حساب المضروب

يناسب المضروب هذا الأسلوب لأن تعريفه الرياضي نفسه ذاتي: مضروب العدد `n` يساوي `n` مضروبًا في مضروب `n - 1`، ومضروب الصفر يساوي 1.

```javascript
function factorial(n) {
  if (n < 0) {
    throw new RangeError("المضروب غير معرَّف للأعداد السالبة");
  }
  if (n === 0) {
    return 1; // حالة التوقف
  }
  return n * factorial(n - 1); // الخطوة الذاتية
}

console.log(factorial(5)); // 120
```

## كيف يجري التنفيذ؟

عند استدعاء `factorial(5)` تؤجل كل دالة عملية الضرب إلى أن يعود إليها ناتج الاستدعاء الذي يليها:

```
factorial(5) = 5 * factorial(4)
factorial(4) = 4 * factorial(3)
factorial(3) = 3 * factorial(2)
factorial(2) = 2 * factorial(1)
factorial(1) = 1 * factorial(0)
factorial(0) = 1
```

وحين تبلغ السلسلة حالة التوقف تعود النتائج صعودًا: 1 ثم 1 ثم 2 ثم 6 ثم 24 ثم 120.

## ملاحظتان

- **عمق الاستدعاء:** يحجز كل استدعاء إطارًا في مكدّس الاستدعاءات (call stack)، فإذا كان العدد كبيرًا جدًّا أو غابت حالة التوقف امتلأ المكدّس وظهر الخطأ `RangeError: Maximum call stack size exceeded`.
- **دقة الأعداد:** يفقد النوع `Number` دقته بدءًا من `factorial(19)` لأن الناتج يتجاوز `Number.MAX_SAFE_INTEGER`. إذا احتجت إلى قيم أكبر فاستخدم `BigInt`.

لم أشغّل الشيفرة هنا، لكنها قصيرة ويمكنك تجربتها مباشرة في متصفحك أو في `node`.
