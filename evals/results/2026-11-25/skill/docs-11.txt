# توثيق واجهة الطقس

تُرجع واجهة برمجة التطبيقات (API) هذه حالة الطقس الحالية في مدينة تحددها، عبر نقطة نهاية (endpoint) واحدة. أرسل الطلبات عبر البروتوكول الآمن (HTTPS)، وستصلك الاستجابات بصيغة تبادل البيانات (JSON) وبترميز `UTF-8`.

**العنوان الأساسي:**

```
https://api.example.com/v1
```

## المصادقة

يتطلب كل طلب مفتاح وصول ترسله في ترويسة `Authorization`:

```
Authorization: Bearer YOUR_API_KEY
```

احفظ المفتاح في الخادم، ولا تضعه في شيفرة تعمل في المتصفح.

## جلب حالة الطقس

```
GET /weather
```

### معاملات الاستعلام

| المعامل | النوع | إلزامي | القيمة الافتراضية | الوصف |
|---|---|---|---|---|
| `city` | سلسلة نصية | نعم | لا توجد | اسم المدينة بالعربية أو الإنجليزية، ويُرمَّز قبل وضعه في العنوان. |
| `country` | سلسلة نصية | لا | لا توجد | رمز الدولة المكوّن من حرفين وفق معيار `ISO 3166-1 alpha-2`، مثل `SA`. يفيد في التمييز بين المدن المتشابهة الأسماء. |
| `units` | سلسلة نصية | لا | `metric` | نظام الوحدات: `metric` (درجة مئوية وكيلومتر في الساعة) أو `imperial` (درجة فهرنهايت وميل في الساعة). |
| `lang` | سلسلة نصية | لا | `ar` | لغة اسم المدينة ووصف الطقس في الاستجابة: `ar` أو `en`. |

إذا تشابهت أسماء عدة مدن ولم ترسل `country`، فستُرجع الواجهة بيانات المدينة الأكثر سكانًا.

### مثال للطلب

```bash
curl --get "https://api.example.com/v1/weather" \
  --header "Authorization: Bearer YOUR_API_KEY" \
  --data-urlencode "city=الرياض" \
  --data-urlencode "country=SA" \
  --data-urlencode "units=metric" \
  --data-urlencode "lang=ar"
```

### مثال للاستجابة

عند نجاح الطلب تُرجع الواجهة الرمز `200 OK`:

```json
{
  "city": "الرياض",
  "country": "SA",
  "coordinates": {
    "lat": 24.7136,
    "lon": 46.6753
  },
  "units": "metric",
  "observed_at": "2026-11-25T09:00:00Z",
  "weather": {
    "condition": "partly_cloudy",
    "description": "غائم جزئيًا",
    "temperature": 22.4,
    "feels_like": 21.8,
    "humidity": 38,
    "wind": {
      "speed": 14.5,
      "direction": 320
    }
  }
}
```

### حقول الاستجابة

| الحقل | النوع | الوصف |
|---|---|---|
| `city` | سلسلة نصية | اسم المدينة باللغة المطلوبة. |
| `country` | سلسلة نصية | رمز الدولة. |
| `coordinates.lat` | عدد عشري | خط العرض. |
| `coordinates.lon` | عدد عشري | خط الطول. |
| `units` | سلسلة نصية | نظام الوحدات المستخدم في القيم. |
| `observed_at` | سلسلة نصية | وقت الرصد بالتوقيت العالمي المنسق، وفق معيار `ISO 8601`. |
| `weather.condition` | سلسلة نصية | رمز ثابت لحالة الطقس، لا يتغير بتغير اللغة. |
| `weather.description` | سلسلة نصية | وصف الحالة باللغة المطلوبة، لعرضه على المستخدم. |
| `weather.temperature` | عدد عشري | درجة الحرارة. |
| `weather.feels_like` | عدد عشري | درجة الحرارة المحسوسة. |
| `weather.humidity` | عدد صحيح | نسبة الرطوبة، من 0 إلى 100. |
| `weather.wind.speed` | عدد عشري | سرعة الرياح. |
| `weather.wind.direction` | عدد صحيح | الاتجاه الذي تهب منه الرياح بالدرجات، من 0 إلى 359، ويدل 0 على الشمال. |

القيم الممكنة للحقل `weather.condition`:

| القيمة | المعنى |
|---|---|
| `clear` | صحو |
| `partly_cloudy` | غائم جزئيًا |
| `cloudy` | غائم |
| `rain` | ممطر |
| `thunderstorm` | عاصفة رعدية |
| `snow` | ثلوج |
| `fog` | ضباب |
| `dust` | غبار |

اعتمد في شيفرتك على `condition` لا على `description`؛ فنص الوصف قد يتغير.

## الأخطاء

تأتي الأخطاء كلها بالبنية نفسها. إليك مثلًا استجابة `404 Not Found` عند طلب مدينة غير موجودة:

```json
{
  "error": {
    "code": "city_not_found",
    "message": "لم نعثر على مدينة بهذا الاسم."
  }
}
```

| رمز الحالة | رمز الخطأ | السبب | الحل |
|---|---|---|---|
| `400` | `invalid_parameter` | المعامل `city` مفقود، أو قيمة أحد المعاملات غير صالحة. | راجع جدول المعاملات وصحّح القيمة. |
| `401` | `unauthorized` | مفتاح الوصول مفقود أو غير صالح. | تحقق من ترويسة `Authorization`. |
| `404` | `city_not_found` | لا توجد مدينة بهذا الاسم. | تحقق من كتابة الاسم ومن رمز الدولة. |
| `429` | `rate_limited` | تجاوزت الحد المسموح، وهو 60 طلبًا في الدقيقة. | انتظر عدد الثواني المذكور في ترويسة `Retry-After`. |
| `500` | `internal_error` | حدث خطأ غير متوقع في الخادم. | أعد المحاولة بعد قليل. |

---

**ملاحظة:** لم تذكر مواصفات محددة، فالعنوان الأساسي وطريقة المصادقة وحد الطلبات وأسماء الحقول ورموز الأخطاء أمثلة افترضتها، فضع مكانها ما يطابق واجهتك الفعلية.
