## الفرق الأساسي

**SQL (قواعد البيانات العلائقية)** تخزّن البيانات في جداول ذات أعمدة محددة مسبقًا، وتربط بينها بعلاقات (مفاتيح أجنبية). أمثلة: PostgreSQL، MySQL، SQL Server.

**NoSQL** مصطلح يجمع عدة أنواع لا تعتمد النموذج الجدولي، وكل نوع مصمم لمشكلة مختلفة:

- **مستندات** (MongoDB): بيانات بصيغة شبيهة بـ JSON.
- **مفتاح–قيمة** (Redis، DynamoDB): بحث سريع جدًا بالمفتاح.
- **أعمدة واسعة** (Cassandra): كتابة بكميات هائلة موزعة على خوادم كثيرة.
- **رسوم بيانية** (Neo4j): بيانات تغلب عليها العلاقات المتشابكة.

## المقارنة

| الجانب | SQL | NoSQL |
|---|---|---|
| المخطط (Schema) | ثابت ومحدد مسبقًا | مرن، يتغير من سجل لآخر |
| العلاقات | JOIN قوي بين الجداول | ضعيف أو غائب غالبًا؛ البيانات تُضمَّن أو تُكرَّر |
| المعاملات | ACID كامل افتراضيًا | يختلف؛ كثير منها يقدّم اتساقًا نهائيًا (eventual consistency) |
| التوسع | عمودي أساسًا (خادم أقوى)، والأفقي ممكن لكنه أصعب | أفقي بطبيعته (إضافة خوادم) |
| الاستعلام | لغة موحدة ومرنة لأي سؤال | واجهة خاصة بكل نظام، ومحدودة بطريقة تصميم البيانات |

الفرق العملي الأهم: في SQL تصمّم البيانات أولًا ثم تسأل أي سؤال لاحقًا، أما في NoSQL فتصمّم البيانات حول الاستعلامات التي تعرفها مسبقًا، وتغيير نمط الاستعلام لاحقًا مكلف.

## متى تختار SQL

- البيانات مترابطة (عملاء، طلبات، منتجات، فواتير).
- صحة البيانات حرجة: مدفوعات، مخزون، حسابات.
- تحتاج تقارير واستعلامات تحليلية غير متوقعة مسبقًا.
- لا تعرف بعد كيف سيتطور التطبيق.

## متى تختار NoSQL

- حجم كتابة أو قراءة ضخم يتجاوز قدرة خادم واحد (سجلات، أحداث، بيانات حساسات).
- بيانات متغيرة الشكل فعلًا (كتالوج منتجات بخصائص مختلفة لكل صنف).
- أنماط وصول بسيطة ومعروفة: جلب بالمفتاح، تخزين مؤقت، جلسات المستخدمين.
- بيانات علاقاتها هي الأساس (شبكات اجتماعية، توصيات): قاعدة رسوم بيانية.
- توزيع جغرافي مع توافر عالٍ، وتقبل اتساقًا أضعف.

## التوصية

إن لم يكن لديك سبب واضح لاختيار NoSQL، ابدأ بـ PostgreSQL. هي تغطي معظم التطبيقات، وتدعم أعمدة JSON للبيانات المرنة، وتتحمل أحجامًا أكبر بكثير مما يتوقعه أغلب الناس. انتقل إلى NoSQL حين تظهر مشكلة محددة لا تحلها قاعدة علائقية جيدًا.

وكثير من الأنظمة تجمع الاثنين: SQL للبيانات الأساسية، وRedis للتخزين المؤقت مثلًا.
