## ما اختبارات الوحدات؟

اختبارات الوحدات (Unit Tests) أشهر أنواع الاختبارات الآلية. وهي شيفرة صغيرة تكتبها لتتحقق آليًّا من أن جزءًا محددًا من برنامجك يعمل كما تتوقع، وغالبًا ما يكون هذا الجزء دالة واحدة. تستدعي الدالة بمدخلات معروفة، ثم تقارن نتيجتها بالنتيجة المتوقعة. فإن تطابقتا نجح الاختبار، وإلا فشل وأخبرك بموضع الخلل.

وتسمى «وحدات» لأنها تختبر أصغر جزء قابل للاختبار بمعزل عن بقية النظام، فلا تعتمد على قاعدة بيانات أو شبكة أو واجهة مستخدم.

## لماذا نكتبها؟

- **اكتشاف الأخطاء مبكرًا:** تكشف الخلل لحظة كتابة الشيفرة وقبل أن يصل إلى المستخدمين، وإصلاحه في هذه المرحلة أسهل وأرخص.
- **التعديل بثقة:** إذا أعدت هيكلة الشيفرة (Refactoring) أو أضفت ميزة جديدة، تخبرك الاختبارات فورًا إن كسرت شيئًا كان يعمل.
- **توثيق حي:** تبيّن الاختبارات كيف تُستخدم الدالة وما السلوك المتوقع منها، وتبقى صحيحة ما دامت تنجح.
- **تصميم أفضل:** الشيفرة التي يسهل اختبارها تكون في العادة مقسمة إلى دوال صغيرة، لكل منها مسؤولية واضحة.
- **توفير الوقت:** يشغّل الحاسوب مئات الاختبارات في ثوانٍ، بدلًا من أن تجرب كل حالة يدويًّا بعد كل تعديل.

## مثال بلغة بايثون

لنفترض أن لدينا دالة تحسب السعر بعد الخصم، في ملف اسمه `pricing.py`:

```python
# pricing.py
def apply_discount(price, percent):
    """تعيد السعر بعد تطبيق نسبة الخصم."""
    if price < 0:
        raise ValueError("السعر لا يمكن أن يكون سالبًا")
    if not 0 <= percent <= 100:
        raise ValueError("نسبة الخصم يجب أن تكون بين 0 و100")
    return round(price * (1 - percent / 100), 2)
```

نكتب اختباراتها في ملف منفصل اسمه `test_pricing.py` باستخدام مكتبة `pytest`:

```python
# test_pricing.py
import pytest
from pricing import apply_discount


def test_regular_discount():
    assert apply_discount(200, 25) == 150


def test_zero_discount_keeps_price():
    assert apply_discount(99.99, 0) == 99.99


def test_full_discount_gives_zero():
    assert apply_discount(50, 100) == 0


def test_negative_price_raises_error():
    with pytest.raises(ValueError):
        apply_discount(-10, 20)


def test_invalid_percent_raises_error():
    with pytest.raises(ValueError):
        apply_discount(100, 150)
```

ثبّت المكتبة وشغّل الاختبارات من الطرفية:

```bash
pip install pytest
pytest
```

فتظهر نتيجة مثل هذه:

```
test_pricing.py .....                                    [100%]
5 passed in 0.01s
```

كل نقطة في النتيجة تمثل اختبارًا ناجحًا. ولو أخطأ أحدهم لاحقًا فكتب مثلًا `price * percent / 100` بدل `price * (1 - percent / 100)`، لفشل الاختبار الأول فورًا وعرض لك القيمة المتوقعة والقيمة الفعلية.

## نصائح سريعة

- اختبر الحالات العادية والحالات الحدّية، مثل الصفر و100، والمدخلات الخاطئة أيضًا.
- اجعل كل اختبار يتحقق من سلوك واحد، وسمّه اسمًا يصف هذا السلوك.
- اجعل الاختبارات سريعة ومستقلة بعضها عن بعض، حتى تستطيع تشغيلها باستمرار.

ويمكنني أيضًا أن أشرح لك وحدة `unittest` المضمّنة في بايثون، أو كيف تشغّل الاختبارات آليًّا مع كل إيداع في مستودعك.
