# مكتبة `csv2json`

مكتبة بايثون خفيفة تحوّل ملفات القيم المفصولة بفواصل (CSV) إلى صيغة ترميز كائنات جافاسكربت (JSON) بسطر واحد من الشيفرة. تقرأ المكتبة الملف وتأخذ أسماء الأعمدة من السطر الأول، ثم تُخرج قائمة من الكائنات الجاهزة للحفظ أو للإرسال عبر واجهات برمجة التطبيقات (API).

## المزايا

- تحويل ملف كامل أو نص مباشرة دون إعدادات معقدة.
- دعم الفواصل المخصصة مثل الفاصلة المنقوطة وعلامة الجدولة.
- دعم ترميز `UTF-8` افتراضيًّا، فتظهر النصوص العربية سليمة.
- تحويل القيم الرقمية والمنطقية إلى أنواعها الصحيحة عند الطلب.
- أداة لسطر الأوامر (CLI) تتيح التحويل دون كتابة شيفرة.

## التثبيت

تحتاج المكتبة إلى بايثون 3.8 أو أحدث. ثبّتها بمدير الحزم `pip`:

```bash
pip install csv2json
```

وللتثبيت من المستودع مباشرة:

```bash
git clone https://github.com/username/csv2json.git
cd csv2json
pip install .
```

## الاستخدام السريع

### من داخل بايثون

```python
from csv2json import convert

# تحويل ملف وحفظ النتيجة في ملف جديد
convert("data.csv", "data.json")

# تحويل ملف والحصول على النتيجة قائمةً من القواميس
records = convert("data.csv")
print(records[0])
# {'name': 'سارة', 'age': '29', 'city': 'عمّان'}
```

لاستخدام فاصل مخصص وتحويل الأنواع تلقائيًّا:

```python
records = convert("data.csv", delimiter=";", infer_types=True)
# {'name': 'سارة', 'age': 29, 'city': 'عمّان'}
```

### من سطر الأوامر

```bash
csv2json data.csv -o data.json --indent 2
```

اكتب `csv2json --help` لعرض جميع الخيارات المتاحة.

---

لم تذكر اسم المكتبة، فاستخدمت `csv2json` اسمًا مؤقتًا. استبدل به اسم مكتبتك، وضع رابط مستودعك مكان `username`، وعدّل أسماء الدوال والخيارات مثل `convert` و`infer_types` لتطابق واجهتها الفعلية.
