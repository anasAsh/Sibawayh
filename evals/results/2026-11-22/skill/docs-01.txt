سمّيت المكتبة `csv2json` ودالتها الرئيسية `convert`، وكلاهما اسم افتراضي. استبدل بهما الاسمين الفعليين، وتأكّد من رقم إصدار بايثون الأدنى ومن خيارات سطر الأوامر.

````markdown
# مكتبة `csv2json`

مكتبة بايثون خفيفة تحوّل ملفات CSV إلى JSON بسطر واحد من الشيفرة. تقرأ المكتبة الملف، وتستخرج أسماء الأعمدة من السطر الأول، ثم تُخرج قائمة من الكائنات يمثّل كلٌّ منها صفًّا من البيانات.

## المزايا

- واجهة بسيطة تكفي فيها دالة واحدة لأغلب الحالات.
- دعم الفواصل المخصّصة مثل `;` و`\t`.
- تحويل تلقائي للأرقام والقيم المنطقية إلى أنواعها الصحيحة.
- أداة سطر أوامر (CLI) للاستخدام المباشر من الطرفية.
- لا تعتمد على أي حزمة خارجية، إذ تكتفي بالمكتبة القياسية.

## التثبيت

تتطلّب المكتبة الإصدار 3.8 من بايثون أو أحدث. ثبّتها باستخدام `pip`:

```bash
pip install csv2json
```

## الاستخدام السريع

### من داخل بايثون

```python
from csv2json import convert

# تحويل ملف CSV وحفظ النتيجة في ملف JSON
convert("users.csv", "users.json")

# أو الحصول على البيانات مباشرة قائمةً من القواميس
data = convert("users.csv")
print(data)
```

إذا احتوى الملف `users.csv` على ما يلي:

```csv
name,age,active
سارة,29,true
خالد,34,false
```

فستكون النتيجة:

```json
[
  {"name": "سارة", "age": 29, "active": true},
  {"name": "خالد", "age": 34, "active": false}
]
```

### من سطر الأوامر

```bash
csv2json users.csv -o users.json --indent 2
```

استخدم الخيار `--delimiter` لتحديد فاصل غير الفاصلة، والخيار `--help` لعرض جميع الخيارات المتاحة.
````
